## ⚠️ 화면이 옛날 디자인으로 보인다면

**증상**: IntelliJ에서 재실행해도, 브라우저를 시크릿 모드로 열어도 예전 화면이 그대로 나온다.

**원인**: Windows에 예전에 띄워둔 `javaw -jar weekly-report.jar`(Desktop의 `dist/run.bat`)가
**8099 포트를 먼저 잡고 있어서**, Windows 브라우저의 `localhost:8099`가 WSL의 개발 서버가 아니라
그 **옛날 jar**로 연결된 것이다. WSL과 Windows는 네트워크 네임스페이스가 달라서, Windows에 같은
포트를 쓰는 프로세스가 있으면 그쪽이 우선한다. 그래서 캐시를 지우거나 시크릿 모드로 열어도 소용이 없다.

**확인 방법** (PowerShell):

```powershell
Get-NetTCPConnection -LocalPort 8099 -State Listen |
  ForEach-Object { Get-Process -Id $_.OwningProcess }
```

`javaw`가 나오면 옛 jar가 떠 있는 것이다.

**해결**: 그 프로세스를 종료한 뒤 다시 접속한다.

```powershell
Stop-Process -Id <PID>
```

**제대로 붙었는지 확인**: 페이지 소스에 `href="/css/app-<해시>.css"`처럼 파일명에 해시가 붙어 있으면
새 앱이다. `href="/css/app.css"`면 아직 옛 jar를 보고 있는 것이다.

배포용 jar를 새로 만들려면 `./gradlew bootJar` 후 `build/libs/weekly-report.jar`를 dist 폴더로 복사하면 된다.
